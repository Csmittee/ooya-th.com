Ooya is a home-made soap shop. This repo is its stand-alone website: Thai is the main language (`/`), English is second (`/en/`).

- Plain HTML and CSS, no JavaScript, no framework.
- Everything that is served lives in `public/`. Cloudflare Pages "Build output directory" = `public`, so the notes in the repo root are not published.
- Images are plain Cloudinary addresses only; no image file is committed.
- Domain: https://ooya-th.com/ (also https://ooya-th-com.pages.dev/).
